# PokeBasic

A Pokémon reference site. Browse the Pokédex, moves, items, and type chart, follow classic-game guides, and build/battle-test a team in the Team Lab — all as real, shareable routes with offline PWA support.

**Stack:** Astro · TypeScript · Alpine.js (`@astrojs/alpinejs`) · Tailwind CSS v4 · GSAP · PokéAPI · `@vite-pwa/astro`

**Package manager:** bun

---

## Pages

| Page | Route | Description |
|---|---|---|
| Home | `/` | Franchise news + site updates, quick-access grid, recently viewed |
| Pokédex | `/pokedex` | Game/All/Shiny selector → per-game listings |
| Pokédex listing | `/pokedex/[slug]` | Type filter, sort, search, pagination (also serves Pokémon detail pages) |
| Pokémon detail | `/pokedex/[name]` | Information / Moves / Compare tabs, evolution chain, gen-aware learnset |
| Moves | `/moves` | Filterable move listing (type, gen, category, TM/HM) |
| Move detail | `/moves/[move]` | Full move data, cross-gen comparison table, learned-by Pokémon |
| Items | `/items` | Filterable item listing (category, gen, game, effect) |
| Item detail | `/items/[item]` | Full item data, held-by Pokémon |
| Type Chart | `/types` | 18×18 type effectiveness grid |
| Stats Explorer | `/stats` | BST ranking table across all 1,025 Pokémon |
| Games | `/games` | Per-game walkthroughs (Red/Blue, Gold/Silver, Ruby/Sapphire, Diamond/Pearl) |
| Team Lab | `/team` | 6-slot team builder with Set Editor, battle simulator, and Showdown export |

All routes are statically generated by Astro (~4,000+ pages at build time) for real SEO (titles, descriptions, canonical URLs, Open Graph).

## Features

### Home (`/`)
- Franchise news pulled from Bulbanews + PokémonDB RSS feeds at build time (daily cron rebuild)
- Manually maintained site updates changelog
- Quick-access grid to Type Chart, Stats, Team Lab, Games
- Recently viewed Pokémon/moves/items (persisted to `localStorage`)

### Pokédex (`/pokedex`)
- Selector for All Pokémon, each mainline game (shows only that game's newly introduced Pokémon), and a full Shiny dex
- Listing: type filter, sort (#/Name/BST/Height/Weight), search, pagination
- Detail page tabs:
  - **Information** — stat bars, abilities, species data, type-defense chart, evolution chain diagram
  - **Moves** — gen-filtered learnset table with gen-correct BP/Accuracy/PP/type/category, method filters (Level-up/TM/Egg/Tutor)
  - **Compare** — opens the quick-view modal for side-by-side stat comparison

### Moves (`/moves`)
- Listing filterable by type, generation, and category (Physical/Special/Status); its existing search also resolves hidden, generation-aware TM/HM/TR queries such as `TM24` without changing the cards
- Detail page: full move data, cross-gen comparison table (BP/accuracy/PP/type/category changes highlighted), game-aware TM/HM/TR history, and which Pokémon learn it

### Items (`/items`)
- Listing filterable by category, generation, game, effect type
- Detail page: full description/effect, which Pokémon hold it in the wild

### Type Chart (`/types`)
- Full 18×18 effectiveness grid, gen-accurate across three historical breakpoints (Gen I / Gen II–V / Gen VI+), including documented Gen I bugs (e.g. Ghost vs Psychic)

### Stats Explorer (`/stats`)
- All 1,025 Pokémon ranked by BST or any individual stat
- Type and generation filters, lazy sprite loading, pagination
- Quick-view modal with full stat breakdown

### Games (`/games`)
- Step-by-step guides per generation with progress tracking and completion state

### Team Lab (`/team`)
- **6-slot builder** with drag-to-reorder and GSAP pop-in animations
- **Set Editor** — nature picker, held item picker, EV/IV sliders (508-total enforced), move selector with STAB indicators, per-slot Showdown export
- **Team analysis** — synergy score, offensive coverage %, common weaknesses, speed tiers
- **Battle Simulator** — full turn-based battles vs. a random CPU team using the Gen 9 damage formula (STAB, effectiveness, crits, burn, stat stages, weather, held items), CPU AI with switch/setup/status logic, Showdown-style colour-coded turn log, GSAP hit/faint animations

### Cross-cutting
- **Dark mode** — Tailwind v4 `dark:` variants everywhere, Alpine store persisted to `localStorage`, OLED true-black theme
- **Omnibox search** — header search spans Pokémon, moves, items, and types; `/` keyboard shortcut to focus
- **PWA/offline** — installable, service worker via `@vite-pwa/astro`, cached sprites and API responses

## Architecture

### Cache (L1 + L2)

```
fetch() call
  └── L1: in-memory Map (same session, instant)
        └── L2: IndexedDB via idb-cache.ts (TTL varies by data type)
              └── PokéAPI network request (fallback)
```

### Build vs. runtime data

| Data | Strategy |
|---|---|
| Moves / Items listings | Build-time, local JSON |
| Pokémon listing manifest | Build-time, slim JSON |
| Pokémon detail, learnsets | Runtime + IndexedDB cache |
| Franchise news | Build-time, daily GitHub Action rebuild |

### Key rules

- `fetch()` only lives in `src/lib/api/pokeapi.ts`
- Logic files accept plain data — no DOM access, no Alpine imports
- `src/entrypoint.ts` is the single place that registers all Alpine stores and components
- HTML building goes through `src/ui/` helpers

## Deployment

Deployed to GitHub Pages via `withastro/action`. The workflow lives at `.github/workflows/deploy.yml`, triggers on every push to `main`, and also rebuilds daily (`0 6 * * *`) to keep the news feed fresh.
